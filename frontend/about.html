PROJECT ABSTRACT

Project overview

CerviCare is an academic prototype exploring how a Random Forest classifier and feature ranking can be applied to structured records from the UCI Cervical Cancer (Risk Factors) dataset. The application demonstrates preprocessing, grouped evaluation, model comparison, and careful presentation of a predicted Biopsy label. The output is experimental and is not a clinical recommendation.

01 / CONTEXT

Problem statement & motivation

The project studies whether a small set of structured questionnaire fields can classify a biopsy outcome in a historical dataset. Its motivation is to demonstrate an end-to-end predictive analytics workflow and explain model behavior without presenting a prediction as a diagnosis.

Existing and proposed system

The source dataset contains clinical and behavioral fields, missing values, repeated profiles, and several outcome columns. CerviCare selects Biopsy as its target, excludes other outcomes and diagnosis indicators from inputs, and uses a fitted preprocessing-and-classification pipeline with a grouped train/test evaluation.

02 / APPROACH

Project scope

CerviCare uses a Random Forest classifier to create a screening-support classification from selected questionnaire fields. It uses a saved preprocessing-and-model pipeline, reports held-out performance, and does not store questionnaire responses on the server.

Objectives

  • Inspect the source data and avoid outcome leakage.
  • Fit imputation and scaling only within training data.
  • Compare Random Forest with Logistic Regression and Decision Tree baselines.
  • Report model performance and feature importance with limitations.

03 / MACHINE LEARNING

Workflow & Random Forest

A Random Forest combines many decision trees. Each tree is trained on a sampled view of the training data and considers subsets of features; their votes produce the final class. The ensemble can model nonlinear patterns, but does not guarantee accurate or clinically useful predictions.

The preprocessing pipeline imputes age with a training-fitted median and binary fields with a training-fitted most-frequent value. The same saved pipeline is applied at prediction time. “Don't know” remains missing and is imputed; it is never converted to “No.”

04 / EXPLAINABILITY

Feature ranking

Random Forest impurity-based feature importance ranks inputs by their usefulness in the fitted model. This is a description of model behavior, not proof of medical causation or clinical significance.

05 / DATA & METHOD

Dataset and methodology

The source dataset contains 858 records and 36 original columns, including 803 negative and 55 positive Biopsy labels. Biopsy is the selected target; it is a recorded biopsy outcome, not a direct clinical cancer diagnosis. The only model inputs are Age, Smokes, and STDs. Other screening outcomes and diagnosis indicators are excluded to reduce target leakage. Identical input profiles are kept within the same evaluation partition.

The held-out test results are accuracy, precision, recall, F1, ROC-AUC, average precision, and a confusion matrix. Due to the small positive class and grouped split, all positive-class estimates are uncertain. Model performance is not optimized by replacing the split or fabricating values.

06 / LIMITATIONS

Limitations & future enhancements

The UCI dataset has 858 records, including repeated rows, and missing values. The project preserves all source rows; 55 records have a positive Biopsy label. This imbalance makes positive-class performance estimates uncertain. The dataset is historical and does not establish performance for any present-day population or clinical setting.

Future work would require larger, representative, externally validated data; calibration and threshold review with qualified clinical collaborators; and independent evaluation of privacy, accessibility, and fairness. No clinical deployment is proposed.

06 / PLEASE READ

Medical disclaimer

Predictions are experimental model outputs from a historical dataset. CerviCare cannot diagnose cervical cancer: a negative prediction does not rule out disease, and a positive prediction does not confirm it. A healthcare professional should interpret screening concerns. This application does not replace recommended medical screening.
