A TRANSPARENT WORKFLOW

How the system works.

Each step uses the existing fitted model pipeline and keeps the model's scope visible.

  1. 01

    Questionnaire

    Enter only age, smoking status, and STI history. No identity or contact details.

  2. 02

    Preprocessing

    The saved training pipeline handles missing answers consistently with model training.

  3. 03

    Random Forest

    The trained classifier predicts a historical biopsy-label class from those three inputs.

  4. 04

    Contextual result

    See the model class with limitations; it is not a diagnosis or personal risk estimate.

WHY SCREENING AWARENESS MATTERS

Use information to support—not replace—care.

Recommended screening and follow-up are guided by healthcare professionals. CerviCare is an academic demonstration of a data workflow, not a screening recommendation or a substitute for clinical care.

METHOD & TECHNOLOGY

Built for transparent exploration.

Age, smoking status, and aggregate STI history are the only model inputs. Biopsy is the target label; other outcomes and diagnosis indicators are excluded to reduce leakage.

BUILT ON A PUBLIC DATASET

Real observations. Honest limitations.

Trained using the UCI Cervical Cancer (Risk Factors) dataset. The original data contains missing values and relatively few positive biopsy outcomes.

Medical disclaimer

Predictions are experimental model outputs from a historical dataset. CerviCare cannot diagnose cervical cancer: a negative prediction does not rule out disease, and a positive prediction does not confirm it. A healthcare professional should interpret screening concerns. This application does not replace recommended medical screening.
